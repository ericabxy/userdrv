# Userdrv

Userdrv is a fork of Xboxdrv to patch bugs and experiment with new features.

1. patch a bug that causes xboxdrv to take up to 60s to initialize a new uinput device
2. add support for C and Z buttons
3. add hotplug support for controllers other than Xbox
4. improve installation and configuration user experience
5. add support for "trackball" style controls

See History of this file for further instructions.
